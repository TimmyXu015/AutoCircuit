**补充测量数据**
- **OTA 本身（与 Round 1 一致）：** M1 gm 3.14 µS，Id 117 nA，gm/Id 26.9（region 3，亚阈值）；M3/M4 region 2，gm/Id 15.3。由 stb 反推：A0·β = 6.42（S1），β = Cfb/(Cc+Cfb+Cin) = 0.0909 → A0 ≈ 70.7；S2 得到同样的 70.7。
- **有效输入电容：** M1/M2 的 cgg 为 17.6 / 17.9 fF（课件例子取 Cin = 500 fF）。相对 Cc = 50 pF 可以忽略（β 只变化约 0.03%）。两端的 cgg 相差约 0.3 fF。
- **DC 失调：** o = n = 0.9054 V，比 VREF 高 5.4 mV。这是 5T 在单位直流反馈下的系统失调：M1 的 Vds 为 0.77 V，M2 为 0.35 V。
- **噪声分解（前 10，0.1–250 Hz 输出噪声积分，见 `B_real_S*_noisesummary_0p1_250.txt`）：** S1 依次为 M1 fn 49.6%，M2 fn 46.2%，M4 fn 2.0%，M3 fn 1.9%，RFP rn 0.17%，RFN rn 0.17%，然后是 M4/M3/M2/M1 的 id 项（各 ≤0.03%）。S2 的排序相同，RFP/RFN 各占 0.02%。**理想 tb 的噪声 100% 来自两只 Rfb**；理想 S1 的 3.26 µVrms 本身就超过 3 µVrms 指标，理想 S2 为 1.03 µVrms。
- **Transient：** 输入正弦从 VREF 起步，DC OP 起点就是工作点，前 0.5 s 没有明显的长时间常数漂移。增益取最后 0.1 s 的峰峰值 ÷ 2vd。5T S2 在 5 mVpk 时增益从 41.22 降到 40.81（−1%），输出范围 0.71–1.12 V，没有削顶。

## 3. 失败原因（只陈述数据）

1. **增益短缺完全由 A0β 决定。** 实测闭环增益与 (Cc/Cfb)·A0β/(1+A0β) 一致：S1 为 10×6.42/7.42 = 8.66，S2 为 100×0.70/1.70 = 41.2。S2 的 β ≈ 1/101，而 A0 ≈ 71，所以 A0β < 1。
2. 要让 S2 达到 40±2 dB 的下限 38 dB（增益 79.4），需要 A0β ≥ 3.85，对应 A0 ≳ 390（≈52 dB）。要把增益误差压到 1%，需要 A0β ≈ 99，对应 A0 ≈ 1e4。**这只是对上面这个关系式的代数推算，不是设计建议。**
3. 有限 A0 同时把 fL 往下拉（S1 0.088 Hz，S2 0.042 Hz；理想均为 0.100 Hz），也把 CMRR 限制在约 55 dB（这还是元件完全匹配、没有 DRL 的情况）。
4. 噪声：这个 A3 OTA 的输入对（M1/M2 10u/1u）1/f 噪声很大，单级等效约 47–51 µVrms，比 3 µV 高一个数量级以上。
