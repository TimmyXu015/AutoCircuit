## 电路（全部为新 cell，R4 / R5 的 cell 没有修改）

- **`ece203_r6a_fd_ota`：最小对称全差分 OTA1。**
  - NMOS 输入对 10u/8u（与 R4 相同）。
  - **两侧都加** NMOS 局部 cascode（10u/4u，VCAS 1.10）。
  - 对称 PMOS 负载 2u/4u，栅极接 VCMFB，没有二极管侧。
  - 尾电流管 MT 8u/4u，实际电流 232.6 nA，每侧 116 nA。
  - 已核实极性：INP 升高时 ON 下降。闭环差模增益 **+94.56**（理想值 100，与 R3C 单端 C OTA 的 94.22 基本一致）。
- **`ece203_r6a_cmfb`：真实 MOS CMFB。**
  - 结构：两对 NMOS 差分-差分（DD）对（4u/2u），一对比较 OP 与参考 vrc，另一对比较 ON 与 vrc。
  - 尾电流由 IBIAS 镜像，每对 50 nA。
  - vrc 一侧的漏极电流汇总到二极管 PMOS MD（1u/4u），MD 产生 VCMFB。
  - 已核实为负反馈。差模摆动在两对之间对称抵消。
  - **系统性失调：** 输出 CM 稳定在 **0.8789 V**，比 VREF 低 21 mV。原因是 MD 与 M3/M4 的镜像比不精确：MD 63.4 nA，负载 116 nA。
- **测试台 `ece203_r6a_tb`：**
  - 人体和 3 个电极沿用 R4 模型（右腿电极 1 MΩ + rs）。
  - 电容反馈 Cc 50 pF / Cfb 0.5 pF / **理想 Rfb**。
  - 输入、输出都有理想换向器（chen = 0 时冻结为直通）。
  - **复用真实 R4 DRL OTA**（`ece203_r4_drl_ota`，CM 检测 rcm 10 GΩ + ccm 1 pF），经 1 MΩ 驱动右腿。
  - 理想偏置：VREF、VCAS、IB 50 nA、IBD 50 nA，与 R4 的 A / B 阶段一样属于诊断性质，不计为合规偏置。
  - 输出端没有 LP。
- **两个扰动：**
  - `d_body`：0.1 µA、60 Hz 的人体电流；
  - `d_ota`：向 op 和 on 各注入相等的 1 nA 共模电流。
- **两个误差：**
  - e_in = (inp + inn)/2 − VREF（放大器侧电极节点）；
  - e_out = (op + on)/2 − VREF。
- **功耗（真实模式）：**
  - 主 OTA + CMFB + IB：I_VDD = 385.6 nA；
  - DRL：I_VDDD = 283.1 nA；
  - 合计 668.7 nA，即 1.20 µW（包含理想偏置源本身的 100 nA）。

## A — 2×2 被控对象与单控制量门槛

数据：`control_matrix.csv`、`r6a_stageA_closedloop.csv`、`stageA/`。

**A1 被控对象 P [Spectre，真实 MOS + 理想执行器]：**
- u_body 是右腿处的理想电压源。
- u_OTAcm 是 vg 上的**纯交流**注入：DC 仍由真实 CMFB 经过 1 TΩ 提供，再用 1e6 F 电容把交流耦合进来，所以 1 mHz 以上 CMFB 环路相当于断开。
- 人体没有被理想源锁死，body 只经过 1 MΩ 电极受驱动。

- **P 满秩，并且近似下三角：**
  - 人体共模经 Cc 进入 OTA 输入共模，再到输出共模，这条交叉耦合很强（6.9 V/V，CMFB 断开时）；
  - OTA 共模几乎不影响人体（约 0.01–0.03 V/V）。
  - RGA 约等于 1，说明配对关系很清楚：u_body 对应 e_in，u_OTAcm 对应 e_out。
- **开环扰动响应：**
  - d_body 在 60 Hz 时：e_in 5.3 mV，e_out 36 mV；
  - d_ota 在 1 Hz 时：e_out 0.59 V/nA，e_in 5.3 µV。

**A2 / A3 闭环 [Ideal-diag：理想静态 VCVS 控制器 K = 1000，挂在同一个被控对象上；Analytic 推算与 Spectre 结果一致到第 3 位有效数字]：**

| 控制方式 | d_body：e_in @60 Hz | d_body：e_out @60 Hz | d_ota：e_in @1 Hz | d_ota：e_out @1 Hz |
|---|---|---|---|---|
| 开环 | 5.31 mV | 36.4 mV | 5.3 µV | 593 mV |
| 理想独立控制（对角 K） | **5.3 µV** | 3.5e-11 V | ~0 | **0.56 µV** |
| **理想 H0：e = e_in + e_out 同时驱动两个执行器** | **5.34 mV（没有抑制）** | 5.34 mV | **0.56 mV（从 OTA 泄漏到人体）** | 0.56 mV |
| H0，α = 0.01 / 0.1 / 10（推算） | 4.6 / 5.0 / 5.1 mV | 461 / 50 / 0.5 mV | 0.51 / 0.56 / 0.56 mV | 51 / 5.6 / 0.056 mV |

**结论：H0 BLOCKED。**
- 单一误差只能把**加权和**压到零。由于 |P22| ≈ 1000 ≫ |P11| ≈ 1，这个唯一的控制量几乎全部由 OTA 执行端吸收：
  - 人体扰动下 e_in 完全没有被压低（5.3 mV，等于开环值）；
  - OTA 内部的共模扰动反而通过 DRL 执行端被**推到人体上**（e_in 0.56 mV，是开环的 100 倍）。
- 无论 α 取多少，都无法同时压住两个独立扰动。这是控制矩阵秩为 1 的结构性限制，和增益大小无关。
- **一个标量 DRL 驱动不能充当 CMFB。**

## C — 一个协同候选 H2：DRL 的 CM 检测信号前馈到 CMFB 参考 [Spectre]

数据：`stageC/`，`comparison.csv` 的第 5 行。

- **做法：**
  - 保留两个局部环路，即 DRL 控 e_in、CMFB 控 e_out。
  - 增加两只无源电阻：vrc = VREF + kff·(cm − VREF)，即 **共享 DRL 已有的输入共模检测节点 cm**，不另加共模传感器。
  - kff 从同一个真实电路实测得到：取 60 Hz 时的 −e_out/(cm − VREF) = **0.0101 − j1.6e-5**。实现为 R(cm → vrc) = 0.98 TΩ，R(vrc → VREF) = 10 GΩ。在实际电路中需要用 pseudo-R 实现，这一点**尚未验证**。
- **用过的一次方向性修正：** 最初设想从 DRL 输出 drlr 前馈，但实测需要的 kff 是 −0.0061（负值），用无源分压无法实现，所以改用 cm 节点（正值，近似纯实数）。
- **公平对照：** kff = 0 就是 B，使用同一套 MOS 和偏置。

| 指标 | B 独立环路 | C H2 前馈 | 变化 |
|---|---|---|---|
| d_body：e_out @60 Hz（AC） | 377 µV | **32.8 µV** | 降到约 1/11 |
| tran：e_out 峰峰值（60 Hz） | 0.80 mV | **0.066 mV** | 降到约 1/12 |
| d_body：e_in | 39.5 mV | 39.5 mV | 不变 |
| d_ota：e_out / e_in | 0.82 mV / 0.12 µV | 0.82 mV / 0.12 µV | 不变（前馈不处理 OTA 内部扰动） |
| 差模增益 @100 Hz / CMRR60 | 94.56 / 108.8 dB | 94.56 / 108.9 dB | 不变 |
| vod 峰峰值（60 Hz 干扰时） | 0.94 mV | 0.93 mV | 基本不变 |
| CMFB PM / DRL PM | 73.5° / 90.3° | 76.0° / 90.3° | 不变或略好 |
| 静态电流 | 668.7 nA | 668.7 nA | 0（只增加两只 TΩ 级电阻） |

**判定：WORKS BUT NO BENEFIT YET。**
- 前馈确实把人体干扰引起的输出共模误差降低约 11–12 倍，两个环路都稳定，静态电流也没有增加。
- 但是在 B 中这个误差本来就只有 0.8 mV 峰峰值，相对输出余量（数百 mV）可以忽略。差模输出、CMRR 和 e_in 都没有改善。
- 共享的只是 DRL 的 CM 检测节点。**没有省掉任何放大器或偏置支路**，反而增加了两只 TΩ 级电阻。
- 所以不能称为有优势的创新结构。
- 只有在后续 chopper 或输出级把输出共模余量用得很紧时，这个前馈才可能有价值，目前**没有证据**。

## D — 全差分理想 chopper（同一个 FD OTA，2 kHz）[Ideal-diag 开关 + 真实 MOS，1 次 PSS]

数据：`ideal_chop_waveforms.csv`、`stageD/`。

- **结构：** 输入换向器放在 p / n 和 OTA 输入之间，输出换向器放在 op / on 和反馈节点 fp / fn 之间。
  - CMFB 检测的是 OTA 输出 op / on，在输出换向之前；共模不受换向影响，所以**不需要单端 EINV / VCVS**。
  - 真实 CMFB 和真实 DRL 都保持闭环。
- **D1：PSS（2 kHz，30 次谐波）+ PAC（1–250 Hz）：**
  - 解调后差模增益 |H| 在 10 / 100 Hz 为 93.39 / **93.43**，是静态值 94.56 的 **0.988 倍**，相位 −0.5°。
  - PSS 稳态时 Vod 纹波峰峰值约 7e-13 V，Vocm 纹波峰峰值约 6e-15 V；op / on 停在 0.8789 V，vg 不动，icm 纹波约 0。
  - 差模输入引起的输出 CM（PAC）为 5.7e-11 V/V。
  - **注意：** 纹波为零只是因为电路完全对称、没有失调和失配。这是理想诊断，不代表真实 chopper 也没有纹波。
- **D2：额外加 1 mV OTA 输入失调（理想 VOS 放在输入换向器之后），20 ms tran（未到稳态，τ 约 1.6 s）[Ideal-diag]：**
  - 静态（chen 0）：Vod 为 1.0 mV DC（失调在 DC 下的增益为 1），无纹波，Vocm 0.8789 V。
  - 斩波（chen 1）：
    - **Vod 纹波峰峰值 190 mV**（2 kHz 方波，平均值 −89 mV，还在缓慢变化）；
    - op 摆动 0.76–0.94 V，on 摆动 0.75–0.93 V；
    - **Vocm 在一个相位里下陷到约 0.845 V（峰峰值 34 mV）。**
  - **解读：**
    - 失调纹波以**差模**形式出现在 Vod 上（全差分的预期行为：不会像 R5 单端结构那样变成 33 mV 的共模 / 单端纹波）。
    - 但当某一相 Vop − Von 达到约 185 mV 时，**DD-pair CMFB 超出线性范围**（亚阈值 tanh 约 ±2nUT），输出 CM 被拉低约 34 mV。
    - 换句话说，**CMFB 的线性范围成为 FD chopper 和失调纹波的新瓶颈。**
    - 这仍是理想开关 + 理想失调 + 未稳态的诊断，不能作为真实 chopper 的证据；也**没有**测噪声。

## 回报（三句话）

1. **简单共用一个误差信号不能用：** 用 e_in + α·e_out 同时驱动右腿和 OTA 负载，在两个独立扰动下任何 α 都只能压住加权和；人体干扰下 e_in 完全没被抑制，OTA 内部扰动还被推到人体上（H0 BLOCKED，有理想诊断和推算两方面的证据）。
2. **双自由度协同（H2）能稳定工作，但不优于两个独立环路：** 共享 DRL 的 CM 检测并前馈到 CMFB 参考后，输出共模误差降低约 11 倍，但增益、CMRR、e_in、功耗和器件数都没有改善（WORKS BUT NO BENEFIT YET）。真实 MOS 的独立 DRL + CMFB 本身就成立：CMRR 108.8 dB，PM 90° / 73.5°。
3. **可以继续用于真实 MOS chopper 的差分输出是有的：** 同一个 FD OTA + 真实 CMFB 在理想 2 kHz 斩波下增益保持 0.988 倍，共模不受换向影响；但加入 1 mV 失调后会出现 190 mV 峰峰值差模纹波，DD CMFB 也在大差模摆幅下失去线性。实际做 chopper 前需要先解决纹波（RRL）和 CMFB 线性范围的问题。

本轮到此停止，不进入 Round 6B。
