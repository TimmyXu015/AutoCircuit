## 1. 因果结论（C0 = 1M/4M，100 Hz，相对全理想参考 92.83 = 39.35 dB）

| 环节 | 实测 | 理想 | 损失 | 占总损失 |
|---|---|---|---|---|
| A1/A2：\|(o1−o2)/v_d\| | 6.25 | 24.99 | −12.04 dB | **78.7 %** |
| A3 自身（有限增益 + 自己的 R1/R2 反馈网络），RC 不接时 | 2.92 | 4.00 | −2.74 dB | **17.9 %** |
| 输出 RC 对 A3 输出的负载 | 2.75（接 RC） vs 2.92（不接） | — | −0.51 dB | **3.3 %** |
| RC 本身的 250 Hz 滤波 \|out/o3\| | 0.9286 | 0.9286 | 0 | 是设计的滤波，不是损失 |
| 合计 \|out/v_d\| | 15.94（24.05 dB） | 92.83 | −15.30 dB | 100 % |

以上占比是实测 dB 损失的分解（三段相乘），不是模型推算。

**机理（实测量 + 用来解释的近似模型）**
- A1 的开环输出阻抗 Zout_ol = 2.19 GΩ（`ece203_load_a1ol_tb`，10 Hz），开环增益 A0 = 14191。电容反馈闭环后 Zout_cl = **4.0 MΩ**（`ece203_load_a1_tb`，10 Hz）。近似模型 Zout_cl ≈ Zout_ol/(1 + A0·β)，β ≈ Cf/(Cf+Cc) = 1/26，算出来是 4.0 MΩ，和实测一致。
- A3 两个输入端的阻抗不一样（单端驱动、另一端接 vref，10 Hz）：**端口 A**（接 o1，R1 进入反相求和点 n3）= 1.37 MΩ；**端口 B**（接 o2，经 R1+R2 分压到 vref）= 5.0 MΩ。差模工作时 n3 跟 o1 反向摆动，A1 实际看到的端口 A 阻抗只有 **268 kΩ**；全理想网络里这个值是 556 kΩ。
- 所以 A1 的输出等于 25 × Z_load/(Z_load + 4 MΩ) 的分压。单独接 1 MΩ 实测 4.98（模型 25×1/5 = 5.0）；接 5 MΩ 实测 13.85（模型 25×5/9 = 13.9）。在整链里单端激励时，A1 路 6.57、A2 路 13.85，**两路不对称**。这种不对称把共模转换成差模：60 Hz 下 |out/v_cm| = 1.44，不加 DRL、也没有任何失配时 CMRR 只有 21.4 dB。
- A1 环路在整链里**带内根本没有闭合**：stb 测到 loop 1 的 UGF 只有 0.036 Hz（单独的 A1 带 5 pF 时是 4.5 kHz）。
- 对照实验确认了因果：
  - 把 A3 换成理想 VCVS（同一网络和 RC），A1 仍然只有 4.99，总增益 18.5。说明 A1 的损失不是 A3 造成的。
  - A1/A2 输出端加理想单位增益缓冲，A1/A2 恢复到 24.95，总增益 60.6（35.6 dB），这时只剩 A3 的 2.61。说明一旦 A1 的输出被隔离，就恢复正常。

## 3. Stage B 要点

- **B1（A1 → A3 端口负载）**：A1 单独（无负载）24.95，带 5 pF 时 24.95（fH 4.48 kHz），+1 MΩ 时 4.98，+5 MΩ 时 13.85；在整链里 6.57 / 13.85；加理想缓冲后 24.95。理想缓冲**确实**改变了 A1 的输出负载（缓冲输入阻抗无穷大，A1 等于空载）。
- **B2（A3 有限增益 + 自己的网络）**：A3 由理想源驱动（C0，接 RC）2.61；不接 RC 时 2.76；在整链里 2.75。A3 开环 A0 = 71.1，开环 Zout = 22.8 MΩ，闭环 Zout（o3）= 1.15 MΩ（10 Hz）。VCVS-A3 加同一网络：A3 = 4.00，这时 A1 仍是 4.99。
- **B3（输出 RC 负载）**：在 o3（RC 之前）测，RC 让 A3 增益掉 0.51 dB（整链）/ 0.48 dB（单独）。RC 本身的传递函数 \|out/o3\| 和理想完全相同。不接 RC 的那一行只用来看负载，**它的 out 没有意义，也不能拿来和 250 Hz 指标比**。

按指标逐项（只是对照，不是声明达标）：
- C2 的最大增益 39.05 dB 落在 40 ± 2 dB 内，fL 0.097 Hz 也在 ±10 % 内。
- 但 fH 只有 172 Hz，低于 250 Hz 的 −10 %（225 Hz），**FAIL**。原因是 A3 在高电阻下自己的闭环极点降到约 600 Hz，与 250 Hz 的 RC 叠在一起。
- C2 的 A3 增益仍只有 3.46（−1.25 dB）。
- 输出下摆幅约 0.54 V，加上约 +25 mV 的失调，5 mV 峰值的输入就已经开始削顶。
- C1 增益不够（36.4 dB）。

电阻热噪声（解析估算，四个电阻折算到 A3 差分输入，4kT·2R1(1+R1/R2)，再除以 25 折算到 ECG 输入）：C0 0.13 µVrms，C1 0.41 µVrms，C2 **1.29 µVrms**。仿真中电阻网络在 C2 占总噪声功率的 0.35 %（约 1.1 µV），和估算一致。它单独看不大，但占了 3 µV 总预算的约 40 %（按功率算约 18 %）。
面积：C2 一共要 2×(100 M + 400 M) = 1 GΩ 的片上电阻，按每方 1–2 kΩ 的高阻多晶算要 50–100 万方，不现实。高阻节点对寄生电容也很敏感：0.5 pF 加 400 MΩ 就是约 800 Hz 的极点。

## 5. 建议（只是建议，没有实施）

1. **光改 A3 的接口电阻能救 A1**：R ≥ 100 MΩ 时 A1 只剩 −0.3 dB 损失。根本原因是 A1 的闭环输出阻抗约 4 MΩ，而电阻输入的减法器把它当成了电压源来用。
2. **但只改接口不够**。R 一大，A3（5T，A0 = 71）就成了瓶颈：增益 −1.25 dB，自身带宽约 600 Hz，把最终 fH 拉到 172 Hz；输出摆幅下限约 0.54 V。电阻面积和热噪声也不理想。A3 的增益、带宽、输出级是**另一个需要单独做的设计决定**。
3. **Pareto**：在试过的三点里，C2 是唯一增益进入 ±2 dB 的，但 fH 不合格，电阻也不可实现；C1 增益不够；C0 完全不行。三点**都不是可交付的方案**。
4. **最小的下一个对照实验（不改拓扑）**：固定 C2（或 C1），只把输出 RC 按阻抗比例缩放，例如 RLP 31.8 MΩ / CLP 20 pF，保持 250 Hz，同时减少片上电容。看 A3 负载减轻后 fH 和增益能恢复多少。这能把"RC 负载"和"A3 自身极点"分开，帮助决定 A3 要不要改。
