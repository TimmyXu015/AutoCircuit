## 1. 旧 DD-pair 为什么把差模读成共模（用来指导设计）

旧 CMFB `ece203_r6a_cmfb` 的结构：
- 两对 NMOS 差分对，每对 50 nA：MA1/MA2 比较 OP 与 VREF，MB1/MB2 比较 ON 与 VREF。
- 两对的 VREF 侧漏极电流相加，流入二极管 PMOS MD，MD 的栅压就是 VCMFB。

记 δ = Vd/2，a = 检测器在平衡点的输入失衡（Vcm − VREF 加上偏置失配）。每一对的电流分配 g(x) 关于平衡点奇对称，于是两对之和为：

- Isum = I0·[g(a+δ) + g(a−δ)]
- 对 δ 的偶次项 ≈ I0·g''(a)·δ²
- 换算成等效共模误差：e(δ) ≈ (h'''/h')·a·δ²/2。其中 tanh 型（亚阈值）h'''/h' = −2/Vs²，Vs = 2nUT ≈ 70 mV；平方律 h'''/h' = −0.75/Vov²。

所以偶次误差同时正比于两样东西：平衡点失衡 a，以及 1/Vs²（线性范围越窄越大）。

R6C 旧 CMFB 的实测与此吻合：
- a ≈ −21 mV（直流误差，来自 MD 1u/4u 与 M3 2u/4u 的 VSD/宽度失配）；
- 输入对是 4u/2u、约 25 nA，gm/Id ≈ 27，深亚阈值；
- δ ≈ 47 mV 时，200 Hz 共模分量 3.5 mV。

**只做直流校准（让 a → 0）也能压低这一项，但那不算线性化**，任务书明确要求把它作为对照，不能当成方案。

## 2. 候选 A（本轮第一种方案）：线性化 DD-pair + 二极管 PMOS 输出

| 器件 | 连接 (D G S B) | 尺寸 | 偏置（设计值） |
|---|---|---|---|
| MA1 | VDD OP ta GND | nfetx 0.5u/40u | 约 60 nA，gm/Id ≈ 9 |
| MA2 | VCMFB VREF ta GND | nfetx 0.5u/40u | 约 60 nA |
| MB1 | VDD ON tb GND | nfetx 0.5u/40u | 约 60 nA |
| MB2 | VCMFB VREF tb GND | nfetx 0.5u/40u | 约 60 nA |
| MTA / MTB | ta/tb IBIAS GND GND | nfetx 10u/8u | 栅接 IBIAS（OTA 的 MREF 2u/4u、50 nA），每个约 120 nA |
| MD | VCMFB VCMFB VDD VDD | pfetx 2.085u/4u | 二极管，约 120 nA；平衡时 VCMFB ≈ OTA 所需的 vg（1.32506 V） |

- **线性化机理：** 输入管 W/L 从 4/2 降到 0.5/40，同时电流加大，工作区从深亚阈值移到中等反型（gm/Id 从 27 降到约 9）。等效线性范围 Vs 从约 0.07 V 升到约 0.25–0.35 V；在相同失衡 a 下，偶次误差约降到 1/10–1/20。这是靠单器件特性扫描（`r7a_device_char.csv`，只用于选尺寸，不算候选）得到的。
- **直流零点：** 设计成两对平衡时，MD 电流（两路 VREF 侧电流之和）恰好产生 OTA 负载所需的 vg。MD 宽度按特性数据从 2u 微调到 2.085u。
- **反馈极性：** Vout,cm 上升 → MA1/MB1 电流增大、MA2/MB2 减小 → MD 电流减小 → VCMFB 上升 → PMOS 负载电流减小 → Vout,cm 下降，为负反馈。
- **代价：**
  - 控制器增益 dvg/dVcm 预计约 0.3（旧的约 0.69，理想控制器为 1），所以直流零点必须更准；
  - 控制器电流约 240 nA（旧的约 103 nA），仍低于 0.5 µA 的目标；
  - 输入管面积更大，在 op/on 上增加约 0.1 pF 的栅电容。
- 偏置全部来自已有的理想 IB（经 OTA 的 MREF）和理想 VREF，**没有新增理想源**。

候选 B（第二种明确不同的拓扑）只在 A 的两轮修正都失败时才设计。拟用：电流镜负载的高增益 DD 检测器，加 MOS 电阻和 MOS 电容组成的滞后补偿。

## 3. 事先登记的门槛

### Stage 2：独立检测器测试

测试台：`ece203_r7a_det_tb_<v>`。OP/ON = vcm ± vd/2，VREF 0.9 V，IB 50 nA 加 MREF 复制管，vg 接两只 M3/M4 复制负载，控制器单独用一个电源 VDDC。

| 编号 | 门槛 |
|---|---|
| S1 极性 | 在 vcm = 0.90、vd ∈ [−0.2, 0.2] V 内，dvg/dVcm > 0 |
| S2 增益 | A_ctrl = dvg/dVcm（vcm 0.899/0.901，vd = 0）在 0.2–2 之间；用于预估环路稳定性 |
| S3 直流零点 | Vcm0 = 0.9 + (vg_target − vg(0.9, 0))/A_ctrl，要求 \|Vcm0 − 0.9\| ≤ 1 mV。vg_target 取 Stage 1 理想基线（BUFFERED 10 pF）中 vg 的实测值 |
| S4 差模→共模（直流已校准时） | e(Vd) = [vg(0.90, Vd) − vg(0.90, 0)]/A_ctrl，要求 \|e(±0.10 V)\| ≤ 0.40 mV（按平方律外推，相当于 ±94 mV 差模摆幅下 200 Hz 分量 ≤ 0.2 mV）。同时报告 ±0.05 和 ±0.20 V |
| S5 线性化证明（与直流校准无关） | 在 vcm = 0.88 和 0.92（人为 ±20 mV 失衡）下，\|e(±0.10 V)\| ≤ 同一测试台中旧 DD-pair 对应值的 1/4 |
| S6 余量 | 21 个工作点（7 个 vd × 3 个 vcm）上，所有控制器 MOS 的 \|vds\| − max(\|vdsat\|, 0.1 V) ≥ 0；vg 在 0.3–1.6 V 内 |
| S7 电流 | 控制器自身电流 ≤ 0.5 µA（目标；超出需说明） |

只有 S1、S3、S4、S5、S6 全部通过，才进入 Stage 3。

### Stage 3：系统门槛（照任务书第 3 节，不改动）

- **TG 静止 A 相：**
  - op/on 共模在 0.900 V ± 1 mV；
  - vg 不撞轨；
  - CMFB PM ≥ 60°，DRL PM ≥ 60°；
  - Hpre(100 Hz) 相对理想基线变化 ≤ 5%。
- **2 kHz TG 瞬态，60 ms（20–40 和 40–60 ms 两个窗口）：**
  - 跑满 60 ms；无振荡、无漂移、无削顶；
  - op/on 共模平均偏差 ≤ 1 mV；
  - 100 Hz 差模增益变化 ≤ 5%；
  - **op/on 共模的 200 Hz 分量 ≤ 0.20 mV**；
  - 同时报告边沿尖峰、恢复时间和 vg 波形。
- **功耗：** 控制器电流、I(VDD) + I(VDDD) 全部记录（两路是独立的对地电源，网表核对见报告）。
