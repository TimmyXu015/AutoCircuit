# R7B 预实验：CMFB 输入管等效电容的独立估计（在任何斩波瞬态之前提交）

任务书：[ECE203_round7b_cmfb_gatecap_causality_task.md](../../ECE203_round7b_cmfb_gatecap_causality_task.md)。脚本 `ece203_r7b.il`（任务 `ece203_r7b_cap`，commit `234cd85`）。分析脚本 `r7b_cap_extract.py`，输出 `r7b_cap_estimate.csv`。原始数据在 `raw/cap/`。

## 1. 两种独立方法

### (a) BSIM 工作点电容

- **测试台：** 原样的 R7A 系统 `ece203_r7a_tb_buf_a2`，只仿真、不改动；TG 停在 A 相，vd = 0，DC op。
- **XC.MA1（栅极 = op）：**

| 参数 | 值 |
|---|---|
| ids | 83.09 nA |
| VGS | 0.600 V |
| VDS | 1.500 V |
| 区域 | 2（饱和，中等反型） |
| **cgg** | **109.56 fF** |
| cgs | −99.06 fF（BSIM 符号约定：cgs = −∂Qg/∂Vs，即栅–源电容约 99 fF） |
| cgb | −10.36 fF |
| cgd | −0.13 fF（漏极接 VDD，没有 Miller 放大） |

- XC.MB1（栅极 = on）的数值相同。
- PDK 还在每个器件上附加了寄生子元件（`XC.MA1.cwgs`、`cwgd`、`cwds`，以及结和电阻），`cgg` 不包含这些。

**cgg 不能直接当作加在 op 上的电容。** MA1 的源极（尾节点 ta）会跟着栅极动：

- 一对管子由 op 与固定的 VREF 组成；op 变化时，ta 大约跟随一半。
- 所以 op 看到的有效电容约为 cgg − k·|cgs|，k 是源极跟随系数。

### (b) 独立小信号栅输入导纳（首选）

- **测试台：** 新建 `ece203_r7b_cin_tb`。复制 R7A 的独立测试台，器件是原样的 `ece203_r7a_cmfb_a2`；只在 VOP（或 VON）上加 AC 幅度。
- **偏置：** vcm = 0.899918 V（R7A a2 系统中 op/on 的 DC 值），vd 取 −94 / 0 / +94 mV（斩波时差模摆幅的两个峰值和中点）。
- **计算：**
  - Y_in = 电压源送进栅节点的电流 / 1 V = −i(VOP:PLUS)；
  - C_eff(f) = Im(Y_in)/(2πf)，频率 10 Hz–100 MHz；
  - 结果包含 PDK 的全部寄生子元件，以及源极跟随的实际效果。

| 支路 | vd | C_eff：1 kHz | 100 kHz | 1 MHz | 10 MHz | 100 MHz | Re(Y) @ 1 kHz |
|---|---|---|---|---|---|---|---|
| op（MA1） | 0 | 67.31 fF | **67.38 fF** | 68.86 | 70.75 | 69.68 | −2.4e-14 S |
| op | −94 mV | 71.73 | 71.77 | 72.13 | 71.01 | 69.82 | −7.0e-15 S |
| op | +94 mV | 62.86 | 62.94 | 65.57 | 70.46 | 69.51 | −4.1e-14 S |
| on（MB1） | 0 / ±94 mV | 与 op 镜像（vd 符号相反时数值相同） | | | | | |

- **实部可忽略：** 1 kHz 时 Q = ωC/G > 9000，所以这是纯电容性负载。
- **两种方法一致：** 由 (b) 反推 k = (cgg − C_eff)/|cgs| = 0.426，接近差分对源极约跟随一半的预期（体效应使其略低于 0.5）。

## 2. 登记的估计值（不拟合任何斩波结果）

**C_est = 67.4 fF / 支路**（op 支路，vd = 0，100 kHz）。

- **不确定度：** 62.9–72.1 fF，即约 −7%/+7%。来自 ±94 mV 差模摆幅造成的工作点变化，以及 1 kHz–100 MHz 的频率变化（高频趋向约 70 fF）。
- **含义：** 这就是 R7A 检测器在 op（或 on）上相对 R6D 理想 CMFB 增加的负载。R6D 的理想检测器 ESA/ESB 是 VCVS，输入电容为零，所以 C_est 全部都是"额外电容"。
- **局限：**
  - 这是小信号、准静态的线性等效。TG 边沿时 op/on 的跳变是 mV 到几十 mV 的大信号，而真实 MOS 电容是非线性的，并且与尾节点存在交叉耦合；
  - 固定电容无法复现这种非线性。

## 3. 事先确定的用例（最多 3 个完整 60 ms 仿真）

| 用例 | CCOP（op→gnd!） = CCON（on→gnd!） | cell |
|---|---|---|
| C0 | 0（不放电容） | `ece203_r7b_tb_c0` |
| C1 | **67.4 fF** = C_est | `ece203_r7b_tb_c1` |
| C2 | **134.8 fF** = 2 × C_est | `ece203_r7b_tb_c2` |

- C_est 的不确定度只有 ±7%，不需要 0.5× 用例，所以 C2 保持 2×。
- C2 只用作灵敏度区间，不参与物理归因。
- 三个测试台都由 R6D BUFFERED 的元件列表生成：理想 R6C CMFB、XCD、CLBP/CLBN = 10 pF。除 CCOP/CCON 外没有任何差别，用网表 diff 核对。

## 4. 判定规则（照任务书第 3 节，不改）

- **F = (metric(C1) − metric(C0)) / (metric(R7A_a2) − metric(R6D_ideal))**，对 DM 边沿最大误差和 DM 拟合残差 RMS 分别计算，两个窗口都算。
- **结论分档：**

| 条件 | 结论 |
|---|---|
| 两个比值都在 0.6–1.4，且波形形状和极性与 R7A 相似 | 强支持 |
| 有一个比值在 0.3–0.6，或只有一个指标能复现 | 部分 |
| 两个比值都 < 0.3（或符号相反） | 仅靠电容不足以解释 |
| 基线不符、C_est 不成立、或仿真不完整 | 证据不足（INCONCLUSIVE） |

- **C0 停机门：** C0 与 R6D-R `F_C_buf_10p` 相比，DM 边沿峰值或残差 RMS 差 > 2%，或 Hpre 差 > 0.5%，就停下来排查方法，不解读 C1/C2。
