**结论：没有 Nominal PASS。** 最佳候选 N2（M1/M2 50/40 µm）逐点 de-embed 噪声 2.994 µV（< 3），但输出 RMS / |H100| 为 3.045 µV（> 3）；其余指标全部通过。

## 设置

- **基准：** R5N-L T3（`ece203_r5nl_tb_l36`）：M3/M4 8/36 µm，M1/M2 40/32 µm，MC 10/4，MT 32/4（尾电流 ×4），MREF 2/4，pseudo-R prw 4 µm，CS OTA2，真实 DRL 与偏置。
- **唯一改动：** M1/M2（左右对称）N1 = 45/36 µm，N2 = 50/40 µm。网表确认 `M1/M2 nfet l=36u w=45u`、`l=40u w=50u`，M3/M4 `pfet l=36u w=8u`，OTA2 器件不变，prw=4e-06。
- **新建 cell：** `Project/ece203_r5nn_ota_{n1,n2}`、`ece203_r5nn_tb_{n1,n2}`；ADE state `r5nn_inputpair_n2_best`（在 `ece203_r5nn_tb_n2`）。R5N / R5N-L 的 cell、ADE state 和数据都没有改动。
- **T3 数据：** 直接引用 R5N-L 的 T_l36 结果（同一电路，没有重跑）。T3 的 M1 cgg 4.80 pF 取自 R5N P2（M1/M2 尺寸和偏置与 T3 相同，`round5n/raw/r5n_bias_pilot2.csv`）。
- **功耗：** VDDD 是串在 vddd→vdd 之间的 0 V 电流表，I(VDD) 已包含 DRL 支路，总功耗 = I(VDD) × 1.8 V，没有重复加 I(VDDD)。

### 重点检查

- **饱和余量：** M2 余量 0.0873 → 0.0867 → 0.0863 V，M4 0.0967 → 0.0966 V，基本不变；M1 的 VGS 几乎不变（弱反型，gm/Id 19.2），所以输入对面积增大没有挤压 headroom。
- **输入阻抗：** 最差端（N 端）161 → 162 → 162 MΩ，不变；P 端随栅电容增大从 4.68 下降到 3.86 GΩ，但仍远高于 N 端，不是瓶颈。
- **增益、带宽、功耗：** 增益只降 0.02%，fH 降 0.1 Hz，电流不变。

## 噪声贡献变化与理论预测偏差

- **输入对 1/f 本身符合 1/√(WL)：** 把输入对 1/f 除以电容噪声增益 (Cc + Cfb + Cgg)/Cc（Cc 50 pF，Cfb 0.5 pF，Cgg 取 M1 cgg）后得到 2.134 / 1.891 / 1.697 µV；从 T3 按 1/√(WL) 推算为 2.134 / 1.897 / 1.707 µV，相差不到 0.6%。
- **偏差来源是栅电容的噪声增益：** 噪声增益随 cgg 从 1.106 增大到 1.132、1.161，所有 OTA1 噪声（包括没有改动的镜像）都被同比例放大。镜像 1/f 除以这个增益后三点都是 1.70 µV，与"镜像本身没变"一致。所以理论预测 3.00 / 2.86 µV 比仿真低 0.07 / 0.13 µV。
  - 这个噪声增益是简化估算（只计 M1 的 cgg，忽略其它寄生），不是单独仿真得到的；但它同时解释了输入对和镜像两项的变化。
- **剩余瓶颈：** N2 中输入对 1/f 与镜像 1/f 各 1.97 µV（各约 43.5%），合计约 2.79 µV；热噪声约 0.93 µV，其余约 0.5 µV。继续加大输入对时，镜像项会因噪声增益继续上升，收益递减。
