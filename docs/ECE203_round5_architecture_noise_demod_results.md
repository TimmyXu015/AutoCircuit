## 隔离 S2 测试台（A–D 共用一套接线，`Project/ece203_r5_s2_<stage>_<slot>`）

```
VINP ─Cc─ p ─(Cfb‖Rfb)─ VREF                 输入 commutator（ck1：p→ia, n→ib_；ck2：交换）
VINN ─Cc─ n ─(Cfb‖Rfb)─ fb ◄─────────────┐
p,n ─[S1/S2]─ ia, ib_ ─► OTA1 (XA = ece203_r4_ota，冻结 C OTA，VCAS 1.10) ─► oa1

oa2 ─[槽 2：直通 或 D2 解调：oa2 / 2·VREF−oa2]─► d2 ─IPRB─► fb ──RLP 31.8 MΩ──► out ──CLP 20 pF──┤
                                                                  （反馈取样点 fb 在 OTA2 / 解调之后、LP 之前）
```

- **CS 的极性：** CS 级是反相的，所以 CS 方案中 OTA1 的 INP 接 ib_、INN 接 ia，以保证整体仍是负反馈。已经用 stb 核实：低频环路增益相位 +135°（1 mHz 处在高通区，接近 +180° 的负反馈约定），带内 H 的相位与非反相方案一致（100 Hz 处约 −22°）。
- **偏置：** OTA2 的偏置管栅极接 OTA1 的 IBIAS 节点，镜像出约 53.6 nA。
- **理想源（诊断用，与 Round 4 A/B 相同）：** VREF、VCAS、IB 50 nA、VR1；VR1 只给槽 1 的反相器用。
- **独立电表：** VDD2 只给 OTA2 供电，用来单独测 OTA2 电流。
- **不斩波时：** chen = 0，时钟冻结在第 1 相，两个槽都是直通，所以静态和斩波用的是完全相同的电路。
- **仿真精度：** gmin = iabstol = 1e-18，reltol 1e-6。

## C — 分级噪声归因：OTA2 对整机的影响到底有多大 [Spectre + Approx]（`r5_noise_stage_contributions.csv`）

- **OTA2 自身噪声（折算到 OTA2 自己的输入）[Approx，教学参考]：**
  - CD：约 **4.5 µVrms**，和 OTA1 同一量级。计算方法是用环内 DM 传递 \|out/oa1\|（约 0.79）做近似。
  - CS：约 0.03 µVrms。CS 级自身的 gm 增益已经把它的噪声压得很低。
- **系统权重：** 尽管 CD 自身噪声约 4.5 µV，但它前面有 OTA1 约 108 倍的增益（oa1/vd），**折算到 ECG 输入只剩 0.042 µV**，占整机功率的约 0.0006%。NoiseSummary 中 X2 各器件的输出功率合计约 1e-11 V²，整机约 2.5e-6 V²。
- **判定（按任务书规则）：** OTA2 折算到 ECG 输入的 1/f 噪声 ≪ 0.5 µV。所以**把解调从 OTA2 之前挪到之后，可节省的噪声最多只有约 0.04 µV**，相对 16.7 µV 可以忽略。这只是候选判定，D 节会用波形和 PNoise 直接检验。
- **整机噪声来源：** 约 98.5% 来自 **OTA1 的 flicker**，其中输入对约 12.4 µV、镜像约 10.9 µV。chopper 必须包住 OTA1，镜像管也在被斩波的回路里。

## D — 解调位置对照：D1（OTA1 后）vs D2（OTA2 后），4 kHz [Spectre：真实 MOS + 理想开关 / EINV / 时钟]

数据：`stageD/`，汇总表 `r5_demod_placement.csv`，噪声分组 `stageD/r5_demod_noise_split.csv`。

**为什么选 CD 做这项实验：**
1. 在 C 节里，CD 自身的 1/f 噪声（约 4.5 µV，折算到 OTA2 自己的输入）是所有 OTA2 中最大的，位置差异最容易显现。
2. 主环路 UGF 为 181 kHz，远高于 4 kHz。CS 的 UGF 只有 8 kHz，环路在 4 kHz 附近已接近交越频率。
3. CD 不反相，两种位置都不需要额外校正时钟极性。

**实验设置：**
- 电路就是 B1 的那套，电极、偏置、LP、反馈和信号增益都相同。
- 开关参数相同：rc 1 Ω，ro 1e20 Ω，两相非交叠，死区 10 ns。
- 理想 EINV 在两种方案里都只是一个 VCVS（不带负载、不计噪声）：
  - D1 以 vr1 为中心反相，vr1 取静态 OTA1 输出 DC（1.31308 V）；
  - D2 以 VREF 为中心反相。
- 对照组：同一电路，chen = 0。
- 隔离 S2 测试台（理想 VREF / VCAS / IB 50 nA），**不是整机**。

**解读：**

1. **门控：** PAC 测得的 100 Hz 增益，两种方案都比静态低约 5%，在 10% 以内，**通过**。
   - tran 阶跃里 D1 为 0.896，略超出 10%。原因是 20 ms 内高通基线还没稳定：D1 的斜率 −0.62 V/s，D2 的斜率 −0.67 V/s，都源于启动瞬态。
   - 任务书明确禁止把未稳定的基线当作稳态，所以门控以 PSS / PAC 为准。tran 数据仅保留作参考。
   - 两种方案都没有越轨：PSS 中最低节点 oa2 = 0.68 V，最高 oa1 = 1.71 V。
2. **OTA2 的 1/f 对位置敏感，但原因不是小信号意义上的“有没有被斩波”：**
   - 静态时 OTA2 flicker 折算到输入只有 0.042 µV，D2 为 0.040 µV，D1 却是 1.16 µV（约 28 倍）。
   - 从静态 stb 看，环路增益在 1 Hz–4 kHz 都约为 11，所以“D1 中 OTA1 在 4 kHz 处增益变低”**不能**解释这个差异。
   - PSS 数据给出的原因是：D1 的解调器把 OTA1 未被斩波的输出电平（约 1.5 V，与 vr1 不等）翻转成了**一个 0.6 V 峰峰值的 4 kHz 方波**，再送进 CD 的栅极。在低相（d1 = 0.91 V，oa2 约 0.68 V）时，MSF 的 Vgs 只有约 0.23 V，远低于 Vth 0.567 V，器件几乎关断。OTA2 的工作点在两相间大幅跳变，导致其 1/f 噪声的周期调制和环路增益都变差。
   - **Spectre 结果（ideal-switch 级别）：** D1 让 OTA2 的 1/f 接近任务书设定的“约 1 µV 才有影响”的门槛。D2 让 OTA2 远离解调器方波，因此有优势。
3. **但是对整机总噪声来说，D1 和 D2 的差距很小，**只有 12.17 对 11.76 µV（约 3%）。在两种方案里，主导项都变成了**被 30 个边带折叠的 OTA1 热噪声**，约 11 µV。
4. **PNoise 尚未收敛（边带检查）：**
   - 以 D2 为例，maxsideband 从 30 增加到 50 时，de-embed 结果从 11.76 µV 升到 **14.25 µV（+21%）**，应用型从 5.21 升到 6.19 µV。
   - 原因是理想开关的边沿为 1 ns，OTA1 在 120–200 kHz 范围内仍有增益，所以折叠进来的白噪声随边带数继续增长。
   - 因此 D 节的**绝对噪声数值只是下限**。D1 和 D2 的**相对比较**仍然有效，因为两者都用 30 个边带。
5. **OTA1 flicker 的残留：** 理想斩波后仍有 3.7 / 0.9–1.6 µV（静态为 12.4 / 10.9 µV），不是零。可能原因是 fb 上的方波纹波经 Cfb 回到输入，被再次调制，形成了二次路径。这一点**还没有单独证明**。
6. **纹波是真正的阻塞项：**
   - 两种方案的 fb 都带有 0.36–0.39 V 峰峰值的 4 kHz 方波。一阶 LP（31.8 MΩ / 20 pF，fc 250 Hz）只能把它压到 out 上约 **33 mV 峰峰值**，这相当于 1 mV ECG 信号放大后（约 80 mV）的 40%。
   - 来源是 OTA1 未被斩波的输出电平（静态 1.313 V → 斩波时约 1.5 V）与解调反相中心不一致。
   - 两种位置都存在这个问题。要解决需要纹波抑制环（RRL）、更高的斩波频率或更高阶的 LP，这些都**不在本轮范围**，本轮也没有尝试。
7. **noisetype：** OCEAN 中请求了 `?noisetype "timeaverage"`，但最终网表的 pnoise 行里**没有** noisetype（见 `D*_netlist.scs`，原始数据保存在实验记录本 _raw 目录中），即使用 Spectre 默认值（ADE 只在非默认值时才写入）。由于查询 `spectre -h pnoise` 没有返回内容，**默认值是否为 time-average 还未独立确认**。

**D 节结论：** 在这个隔离测试台、理想开关条件下，**D2（解调放在 OTA2 后）不会差于 D1，而且避免了 D1 让 CD 承受大信号方波、OTA2 1/f 被放大约 28 倍的问题**。但对整机噪声来说，两者只差约 3%，被折叠的 OTA1 热噪声和 33 mV 斩波纹波才是更大的问题。**结论：倾向 D2，原因主要是 OTA2 的工作点和摆幅，而不是噪声。**限制条件：非物理的 EINV、理想开关、PNoise 未收敛、仅为隔离 S2 测试台。

## E — 最佳候选 CS 回到 Round-4 真实 ECG 架构（不斩波）[Spectre，真实偏置 / pseudo-R / 真实 DRL]

数据：`stageE/`，规格表 `r5_final_spec_matrix.csv`。Cell 为 `Project/ece203_r5_ecg_cs_rbpr_tb`，ADE state 为 `r5_final_cs`。

**为什么 E 用 CS 而不是 CD：**
- B 节里 CS 在不斩波条件下的各项指标都更好：增益 92.75，与理想值 92.8（100 × LP 衰减）几乎一致；CD 只有 85.47。
- CS 在 10 Hz 的环路增益为 701，CD 为 11.5。增益精度对器件参数和失配不敏感。
- CS 的 PM 为 87°。
- 两者噪声相同。
- 代价：CS 的 UGF 只有 8 kHz，**如果以后要接 4 kHz chopper，CS 的带宽余量不足**。D 节只验证了 CD，CS 的斩波兼容性**还没有测试**。

**架构说明：**
- 与 Round 4 最终版完全相同：3 个电极 + 人体，pseudo-R W3u/L2u（**没有改动**），真实 DRL OTA + 2 × 1 pF ccm，VDD 加一个 100 nA 参考，PMOS 镜像，VREF / VCAS 电阻分压（VCAS 1.10），LP 31.8 MΩ / 20 pF。
- **唯一改动：** OTA1 输出接到 oa1，CS 级（MCS 4u/2u 加镜像负载 MCL 2u/4u）从 oa1 驱动到 oa，CM2 = 0.5 pF；OTA1 的输入交换；反馈取样点 o 在 OTA2 之后、LP 之前。
- OTA2 的偏置从现有 ib 节点镜像得到，不增加新的电流源。

## 决策备忘（供用户 / GPT 决定下一轮）

1. **输出级问题已经解决。** A 节用理想 buffer 证明了 Round 4 的增益 / fH 失败是 OTA 输出阻抗造成的。真实 CS 第二级在整机中达到 39.27 dB / 249 Hz，PM 87.6°，只多消耗 57 nA。CD 也能用（38.64 dB），但环路增益只有 11.5。
2. **OTA2 的 flicker 对静态整机可以忽略**（折算到 ECG 输入 0.03–0.04 µV，判定规则是小于 0.5 µV 即可忽略）。整机噪声约 99% 来自 OTA1 的输入对和镜像 flicker（12.4 + 10.9 µV）。降噪必须针对 OTA1，可以是 chopper 包住 OTA1 加镜像，或者增大面积。
3. **解调位置：倾向 D2（OTA2 之后）。** D1 会让 OTA2 的输入承受 0.6 V 峰峰值的斩波方波，CD 在一半周期里接近关断，OTA2 的 1/f 被放大到 1.16 µV。不过两种方案的总噪声只差约 3%。
4. **斩波的真正问题：**
   - 33 mV 峰峰值输出纹波，来源是 OTA1 未被斩波的输出电平；
   - 折叠进来的 OTA1 热噪声，30 个边带下约 11 µV，而且随边带数还在增长，PNoise 尚未收敛。
   
   做真实 MOS chopper 之前需要先决定纹波处理方案（RRL、更高的 fch 或二阶 LP），并重新评估 CS 级在 fch 处的环路增益。
5. **仍然 FAIL 的项：**
   - fL 0.077 Hz，由 pseudo-R 决定，本轮按规定没有改；
   - 噪声 16.6 µV，需要 chopper 或改动 OTA1，均属于下一轮的工作。
