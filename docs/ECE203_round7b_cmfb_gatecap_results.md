# ECE203 R7B 结果：CMFB 输入栅电容的因果实验

**判定：栅电容假设成立（强支持，按事先登记的判定规则）。**

- 在理想 CMFB 测试台的 op、on 上各加一只 67.4 fF 的无源电容（C1）。这个值是事先独立测得的 R7A 检测器输入电容，没有用斩波结果拟合。
- 仅这一处改动，就复现了 R7A 相对 R6D 的差模边沿劣化：

| 指标 | 解释比例 F(C1)，两个窗口 |
|---|---|
| DM 边沿最大误差 | 1.023 |
| DM 拟合残差 RMS | 1.001 |
| 100 Hz 增益 | 1.002 |

- 误差波形本身也重合：C1 与 R7A 的 DM 误差波形之差，只有 R7A−R6D 差异的 0.23%；相关系数 1.0000，极性相同。
- 剂量关系：电容加倍（C2，134.8 fF）后，劣化约变成 1.7–2.0 倍。
- **这不是完美证明。** 真实 MOS 栅电容是非线性的，并且与尾节点交叉耦合。本轮只说明：线性等效电容已经足以解释全部的差模劣化，看不到需要其他机制的迹象。
- **本轮没有改进 R7A，也没有调整任何晶体管尺寸。**

## 1. 先独立估计电容，没有拟合（详见 `r7b_cap_plan.md`）

### (a) BSIM 工作点

- **测试台：** 原样的 R7A 系统 `ece203_r7a_tb_buf_a2`，TG 停在 A 相，vd = 0，只仿真不改动。
- **XC.MA1（栅极 = op；XC.MB1 栅极 = on，数值相同）：**
  - ids 83.1 nA，VGS 0.600 V，饱和、中等反型；
  - **cgg 109.6 fF**，cgs −99.1 fF（BSIM 符号约定），cgb −10.4 fF，cgd −0.13 fF（漏极接 VDD，没有 Miller）；
  - PDK 另外附加了寄生子元件 `XC.MA1.cwgs`、`cwgd`、`cwds` 等（`raw/cap/r7b_capop_names.txt`），cgg 不包含它们。

### (b) 独立小信号栅输入导纳（作为 C_est 的依据）

- **测试台：** 新建 `ece203_r7b_cin_tb`，用原样的 `ece203_r7a_cmfb_a2`；只在 VOP 或 VON 上加 AC。
- **偏置：** vcm = 0.899918 V（R7A 系统中 op/on 的 DC 值），vd 取 −94 / 0 / +94 mV。
- **计算：** C_eff = Im(Y_in)/(2πf)，Y_in = −i(VOP:PLUS)/1 V（电压源送进栅节点的电流）。

| 支路 | vd | 1 kHz | 100 kHz | 1 MHz | 10 MHz | 100 MHz |
|---|---|---|---|---|---|---|
| op | 0 | 67.31 fF | **67.38 fF** | 68.86 | 70.75 | 69.68 |
| op | −94 mV | 71.73 | 71.77 | 72.13 | 71.01 | 69.82 |
| op | +94 mV | 62.86 | 62.94 | 65.57 | 70.46 | 69.51 |
| on | 与 op 镜像（vd 符号相反时数值相同） | | | | | |

- **实部可忽略：** 1 kHz 时 Re(Y) 为 −7e-15 到 −4e-14 S，Q = ωC/G > 9000。
- **两种方法一致：**
  - 由 (b) 反推源极跟随系数 k = (cgg − C_eff)/|cgs| = 0.43。差分对的源极（尾节点）约跟随栅极一半，体效应使 k 略低于 0.5。
  - 所以 cgg（110 fF）不是 op 上看到的负载，有效值约 67 fF。
- **这就是"额外电容"：** R6D 的理想检测器是 VCVS，输入电容为零。
- **登记值：C_est = 67.4 fF/支路。** 不确定度 62.9–72.1 fF（±7%），来自差模摆幅造成的工作点变化以及频率变化。
- 因为 ±7% 不算大，按任务书保留 C2 = 2×，没有改成 0.5×。

**波形形状**（40–60 ms，0.1 µs 网格，见 `r7b_edges.png`）：
- C1−R6D 与 R7A−R6D 两条 DM 误差差值曲线的相关系数 **1.0000**，最小二乘比例 **1.001**；
- C1 与 R7A 的残余差别，只有 R7A−R6D 差异 RMS 的 **0.23%**；
- C2 的相关系数 0.9986，比例 1.875；
- 两个边沿（42.5 ms、45.0 ms）上，C1 都与 R7A 重合，极性相同。

**怎么读：**

1. **按登记的规则：** DM 边沿最大误差和 DM 残差 RMS 的 F 都在 0.6–1.4 之内（1.023、1.001），形状和极性也相同，因此判为**强支持**。
2. **差模劣化分三段，C1 都复现了：**
   - **0–2 µs 初始跳变：** 边沿瞬间 op/on 上多出的电容与 fp/fn 之间发生电荷分享；
   - **2–40 µs 恢复段：** 按原来的时间常数衰减，但起点更深；
   - **40–200 µs 平台：** 拟合吸收掉部分误差后留下的偏移；
   - 100 Hz 增益同样下降 1.9%。
3. **剂量关系：** C2 的劣化约是 C1 的 1.7–2.0 倍。说明这一项随额外电容单调、近似线性增长；C2 不参与归因。
4. **"不能降到 1% 以下"的含义：** R7A 报告的 249 µs，是在 250 µs 半周期内、按拟合误差规则最后一次超过 1% 阈值的时刻。它**不是 249 µs 的物理时间常数**。
   - C1 同样如此（248.99 µs），原因是 40–200 µs 的平台偏移（+1.7 mV）一直高于 1% 门槛。平台本身是缓慢变化的，见 `r7b_edges.png` 右上。
   - 本轮没有测量任何极点，不称之为内在极点。
5. **共模方面：**
   - **边沿正尖峰：** 67.4 fF 也基本复现了 R7A 的降低（47.8 → 9.4 mV，F = 0.977）。这支持 R6C 当时未验证的假设：理想检测器尖峰大，是因为 op/on 上缺少电容。
   - **200 Hz 共模：** F 不适用。分母只有 −0.76 µV，是噪声级的差值；R7A 中的 3.9 µV 来自 MOS 检测器和较低的环路增益，与电容无关。
   - **vg 摆动：** C1 为 7.95 mV，R7A 为 1.85 mV。理想控制器跟随尖峰更快，这是控制器本身的差别。
   - 两者的 op/on 共模平均都在 0.9 V ± 0.15 mV 以内。
6. **局限：**
   - 固定线性电容不能代表 MOS 电容随电压的变化（62.9–72.1 fF），以及它与尾节点的交叉耦合；
   - 只做了 tt/27 °C；
   - 结论只针对差模边沿劣化这一项。

## 4. 下一步（只建议一步，本轮不做）

在 R7A 检测器上**降低输入管的有效栅电容**，并在**同一把尺子**下重新检验。例如：
- 缩小输入管面积，同时保持 gm/Id，或在线性度与电容之间折中；
- 或者在 op/on 与检测器之间加隔离。

验收要同时看三样：R7A 已通过的线性度门槛、DM 边沿误差、共模边沿尖峰（降低电容时尖峰会回升）。

本轮**没有**修改任何尺寸。
