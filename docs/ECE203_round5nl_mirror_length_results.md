## 设置

- **基准电路：** R5N P2（`ece203_r5n_tb_n16p16_t4`）。
  - OTA1：M1/M2 40u/32u，M3/M4 8u/16u，MT 32u/4u（尾电流 ×4）。
  - pseudo-R 宽度 prw = 4 µm，CS OTA2，真实 DRL 和偏置，LP 31.8 MΩ / 20 pF。
- **唯一改动：** M3/M4 的 L 改为 24 / 32 / 36 µm，W 保持 8 µm。每次运行的网表里，M3/M4 都确认为 `pfet l=24u/32u/36u w=8u`。
- **新建 cell：** `ece203_r5nl_ota_l<L>`、`ece203_r5nl_tb_l<L>`。`ece203_r5n_*` 的 cell 和 ADE state 都没有修改。
- **P2 对照：** P2 本身也在新 cell `ece203_r5nl_tb_l16` 中按相同器件重跑了一次，用来取得 M3/M4 的工作点；结果与 R5N 的 P2 完全一致（4.069 / 4.143 µV）。
- **功耗：** 真实偏置测试台中，VDDD 是一个 0 V 电流表，接在 vddd 和 vdd 之间，所以 I(VDD) 已经包含 DRL 的 I(VDDD)。总功耗按 I(VDD) × 1.8 V 计，表中也单独列出 I(VDDD)。

## 镜像 1/f 噪声是否按约 1/L 缩放？

**没有，比 1/L 弱。**
- 拟合四个点：镜像 1/f 的 RMS 约正比于 **L^−0.62**。L 加到 2.25 倍时，噪声只降到 0.60 倍；严格 1/L 应降到 0.44 倍。
- **gm 这部分符合预期：** M3 的 gm 约正比于 L^−0.49，这是 √(W/L) 关系在强反型下的表现，gm/Id 从 8.4 降到 5.6。
- **偏差来自器件本身的噪声：** 在同样电流下，M3 自身折算到栅极的 1/f 噪声，只按约 L^−0.13 下降，而不是面积律给出的 L^−0.5。也就是说，在 PDK 模型里，L 变长、VSG 和过驱动随之增大（0.62 → 0.74 V）时，单位面积的 flicker 噪声反而变大。
- 这是从 Spectre 数据反推出来的，**没有单独做器件级的 1/f 测试来验证**。

## 哪项约束最先变差？

- **M1 的 VDS：** M3 的 VSG 变大，n1 节点被拉低，M1 的 VDS 从 0.723 降到 0.604 V，余量从 0.62 降到 0.50 V，仍然很宽。
- **主环路的环路增益：** LG(10 Hz) 从 1547 降到 618，LG 直流值从 1.42e5 降到 4.9e4。这是因为更长的 M3/M4 改变了 n1 节点和 OTA1 的增益。PM 仍有 74.0°。
- **对规格的影响：** 增益 −0.15%，fH −1 Hz，都很小。
- **最紧的余量：** OTA1 里最紧的仍是 M2（0.087 V），与 L 无关，没有恶化。
- **功耗与 CMRR：** 功耗不变；CMRR 89.47 → 89.85 dB，基本不变。
- **总结：** 没有出现 headroom 问题，三个点都有效，都完成了噪声测量。

## 有没有达到 3 µV 的有效候选？没有。

- 最低的是 **T3（L = 36 µm）：3.194 µV（逐点）/ 3.256 µV（应用型）**，比 3 µV 高约 6%。测量带宽仍是 0.1–250 Hz，没有改。
- **现在最大的噪声来源是输入对 M1/M2 的 1/f：** 2.36 µV，占 55%。
  - 只靠镜像，即使把镜像 1/f 降到 0，总噪声也只能到约 2.6 µV（推算）。
  - 按 L^−0.62 外推，镜像大约需要 L ≈ 45–50 µm 才可能让总噪声低于 3 µV。**这只是推算，没有仿真**，而且 M1 VDS 和环路增益会继续下降。
